# memocalendar-lp

iOS アプリ **MemoCalendar** のランディングページとプライバシーポリシー。

- ランディングページ: https://wadashuri.github.io/memocalendar-lp/
- プライバシーポリシー: https://wadashuri.github.io/memocalendar-lp/privacy.html

## このリポジトリがある理由

アプリ本体のリポジトリは private で、GitHub Pages は無料プランだと公開
リポジトリでしか使えない。App Store の申請にはプライバシーポリシーの公開URLが
必須なので、**公開してよいページだけ**をここに分けている。

## 中身の出どころ

ここのファイルは**アプリ本体のリポジトリの `docs/` が原本**。直接編集せず、
向こうを直してから配置し直すこと（手順は本体リポジトリの `docs/README.md`）。
