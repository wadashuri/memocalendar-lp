# notecalendar-lp

iOS アプリ **Note Calendar** のランディングページとプライバシーポリシー。

- ランディングページ: https://wadashuri.github.io/notecalendar-lp/
- プライバシーポリシー: https://wadashuri.github.io/notecalendar-lp/privacy.html

## このリポジトリがある理由

アプリ本体のリポジトリは private で、GitHub Pages は無料プランだと公開
リポジトリでしか使えない。App Store の申請にはプライバシーポリシーの公開URLが
必須なので、**公開してよいページだけ**をここに分けている。

## 中身の出どころ

`index.html` と `privacy.html` は**このリポジトリが原本**。直接編集する。

`screenshots/` だけはアプリ本体のリポジトリの `docs/screenshots/` が原本。
撮り直したら向こうからコピーし直すこと（手順は本体リポジトリの `docs/README.md`）。
